## About

Pet Paradise is a fully designed multi-page website implemented as an IT-213 coursework project. 
It features multiple pages such as a home page, contact page, and product sections. 
The site is styled with custom CSS and enhanced with JavaScript, allowing content to 
dynamically update on the client side based on user interactions. For example, subheaders 
and images change depending on the button clicked on the previous product page. It also features 
an animation commercial created in Adobe Animate, and the site logo and favicon were 
designed in Adobe Photoshop.
